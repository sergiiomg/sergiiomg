## Detalle de proyectos

### Checkpoint

**Red social web para gamers inspirada en comunidades tipo Reddit.**

Checkpoint permite a los usuarios crear publicaciones, comentar, dar me gusta, guardar contenido y seguir a otros usuarios. Además, incluye un sistema de gamificación basado en experiencia, niveles, logros y recompensas.

Entre sus funcionalidades principales destacan:

* Creación e interacción con publicaciones.
* Comentarios, likes y guardado de publicaciones.
* Sistema de seguimiento entre usuarios.
* Experiencia obtenida mediante interacciones.
* Subida de nivel según la experiencia acumulada.
* Logros desbloqueables, como crear publicaciones o seguir usuarios.
* Recompensas cada 5 niveles mediante motes personalizables para el perfil.

**Tecnologías:** Angular, TypeScript, Node.js, Express, MySQL, Postman.

[Repositorio](https://github.com/sergiiomg/checkpoint)

---

### LearnLytics

**Aplicación móvil para estudiantes con análisis inteligente del rendimiento académico.**

LearnLytics permite a los estudiantes registrar su historial de exámenes, asignaturas y sesiones de estudio. La aplicación integra inteligencia artificial mediante la API de OpenAI para generar análisis personalizados sobre el rendimiento del usuario.

La IA puede detectar patrones, fortalezas, debilidades y posibles áreas de mejora, tanto a nivel general como por asignatura.

Funcionalidades principales:

* Registro de exámenes y asignaturas.
* Seguimiento de sesiones de estudio.
* Análisis general del rendimiento académico mediante IA.
* Análisis específico por asignatura.
* Detección de patrones, fortalezas y debilidades.
* Recomendaciones personalizadas para mejorar el estudio.

**Tecnologías:** Ionic, Angular, TypeScript, Node.js, Express, MongoDB, Postman, API de OpenAI.

[Repositorio](https://github.com/sergiiomg/learnlytics)

---

### Vault

**Aplicación de escritorio para la gestión segura de contraseñas.**

Vault es un gestor de contraseñas centrado en la seguridad y la privacidad. Permite crear un vault protegido por una contraseña maestra, necesaria cada vez que se accede a la aplicación.

Dentro del vault, el usuario puede crear entradas con información como usuario, URL, contraseña y anotaciones. También incluye buscador y generador de contraseñas.

Funcionalidades principales:

* Creación de vault protegido por contraseña maestra.
* Gestión de entradas con usuario, URL, contraseña y notas.
* Buscador integrado para localizar credenciales rápidamente.
* Generador de contraseñas.
* Las contraseñas no se muestran directamente.
* Copia segura al portapapeles.
* Limpieza automática del portapapeles tras 30 segundos.

**Tecnologías:** Python.

[Repositorio](https://github.com/sergiiomg/localvault)
